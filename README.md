# Hi, I'm Anish

I build backend services and agent systems. Most of my time goes into working out
where AI-generated code goes wrong.

That second part is my actual job. At **Handshake** I write software engineering
tasks that are used to test AI coding agents, and then grade the code they produce.
Before that I worked on LLM post-training at **Ethara AI**.

## What I've built

**[incident-engineer](https://github.com/anishraja04/incident-engineer)** - two agents
that find and fix real bugs. A fix is only accepted once the full test suite passes.
11 of 11 incidents resolved, against 0 of 11 for a single-prompt baseline.

**[team-task-manager](https://github.com/anishraja04/team-task-manager)** - KaamSathi.
Full-stack team task manager with Django REST, React and PostgreSQL, JWT auth and
role-based access. Live on Railway.

**[ai_resume_generator](https://github.com/anishraja04/ai_resume_generator)** -
Spring Boot REST API with a React front end and a pluggable LLM backend.

**[mermail-expense-tracker](https://github.com/anishraja04/mermail-expense-tracker)** -
an MCP skill that turns receipt emails into an expense ledger. Treats every email as
untrusted input.

**[cloud-native-devops](https://github.com/anishraja04/cloud-native-devops)** -
Terraform for an AWS VPC and EC2, a Dockerised app behind Nginx, and GitHub Actions
deploying on every push.

**[api-etl-pipeline](https://github.com/anishraja04/api-etl-pipeline)** - pulls records
from external REST APIs, cleans up the JSON and loads it into PostgreSQL. FastAPI.
